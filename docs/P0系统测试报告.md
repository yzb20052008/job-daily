## 5. Go / No-Go

### **No-Go（不可按当前状态上线）**

硬阻断：

1. **匿名可上传文件（BUG-P0-01）**  
2. **岗位详情明文电话（BUG-P0-02）**  
3. **地图逆地理不可用（BUG-P0-03）**  

附条件：支付/提现正向未在真实商户下验收 → 资金域单独 **No-Go**，即便上述 3 项修复后也需补一轮支付沙箱/提现联调。

---

## 6. 回归建议（下轮必测）

1. 无 Token / 伪造 Token 上传 → 必须 401/业务拒绝  
2. 详情/列表接口字段：无 `phone` 明文；拨号走 contact + 积分/VIP  
3. 腾讯控制台关闭 Key 签名校验后逆地理、suggestion、选点全通  
4. 报名通知写站内信（依赖 `biz_msg_template`）  
5. 打卡：缺图、超距（把 `clock_range` 改回 2km 后）、过 `end_time`、重复  
6. 结算：`amount` 与核算一致 → 拉起预下单；回调幂等  
7. 提现：有余额申请 → 冻结 → 运营台可见
