# 腾讯地图代理迁移说明

| 项目 | 说明 |
|------|------|
| 参考 | Job-Zp `MapController` / `TencentMapApiSupport` |
| 日期 | 2026-08-29 |

## 能力

| 接口 | 说明 | 鉴权 |
|------|------|------|
| `GET /api/map/reverseGeocoder` | 逆地理 | anon |
| `GET /api/map/geocoder` | 地理编码 | anon |
| `GET /api/map/suggestion` | 关键词搜索 | anon |
| `GET /api/map/ipLocation` | IP 定位 | anon |
| `GET /api/map/nearby` | 附近 POI | **需登录** |
| `GET /job/jobPost/mapConfig` | 下发 mapKey（不下发 sk） | 后台登录 |
| `GET /job/jobPost/map/suggestion` | 后台选点搜索 | 后台登录 |
| `GET /job/jobPost/map/reverseGeocoder` | 后台选点逆地理 | 后台登录 |

## 配置（base_config）

| code | 用途 |
|------|------|
| `map_key` | 腾讯 Key（服务端调 WebService + 前端 GL JS） |
| `map_sk` | 签名密钥，**仅服务端**；未配则不签名 |

脚本：`db/upgrade/V20260829_04_map_config.sql`

## 前端改造

- Mobile：`config/common.js` 逆地理/搜索走 `/api/map/*`；`baseUrl.js` 去掉硬编码 sk
- splash 仍可拉 `map_key` 写入 `mapData.key`（仅地图组件兜底）
- Web：`components/map/selectAddress.vue` 改为腾讯 GL JS + 后台代理

## 验收

- [ ] 基础配置已填 `map_key`（生产务必配 `map_sk`）
- [ ] 小程序定位后能拿到省市区（走 `/api/map/reverseGeocoder`）
- [ ] 后台发岗「选择地址」可搜索、点选、逆地理回填
- [ ] 客户端网络抓包不再出现 `apis.map.qq.com` 直连（渲染地图 JS 除外）
