## 1. 本批修复摘要

### P0

| 项 | 说明 |
|----|------|
| 结算算薪 | `SalaryCalcHelper`：有单价×工时必须一致；否则协商金额（上限 99999.99） |
| 微信/支付宝下单 | 调用 `resolvePaySalaryAmount` 后再统一下单 |
| 余额充值 | 新表 `ums_balance_recharge`；回调验额入账；禁止再误写积分充值表 |
| 转账回调 | `POST /v3/transferNotify`；`transferNew` notify 指向该地址 |
| 提现申请 | `@Transactional` + `lockByUserId(FOR UPDATE)` |
| 提现终态 | 转账 FAIL/CANCELLED 同步 `withdraw_status=失败` 并解冻 |

### P1

| 项 | 说明 |
|----|------|
| 超时取消 | `autoFinishOrder` 走 `OrderStatusMachine` |
| 评价完成 | 双方评完 `assertTransition(4→5)` |
| 打卡规则 | 图片必填、同类型防重、地理围栏 2km、上班时间窗、下班回写工时 |
| 删岗约束 | 已结算禁删；有进行中订单改停招；仅无有效订单可物理删 |

## 3. 验收清单

- [ ] 有单价+工时订单：改金额下单被拒绝；正确金额可支付且回调入账

- [ ] 重复打卡/无图/超距被拒绝；下班后 `duration` 有值
