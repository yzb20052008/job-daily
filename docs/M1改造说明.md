## 2. 菜单脚本说明

执行 `Job-Daily-Admin/db/menu/01_align_job_menus.sql` 后：

1. 旧 `/rms` `/wms` `/bms` 菜单软删除并隐藏
2. 新增一级菜单：**招工管理**、**积分运营**
3. 用户管理下补齐：实名认证、签到、用户VIP、提现账户、支付方式、推荐记录
4. 自动授权给 `role_code=admin`
5. **重新登录**后台即可看到新菜单

---

## 3. 支付宝结算说明

- 接口：`GET /aliPay/appPaySalary?orderId=&amount=`
- 移动端：`workerManage` 启用支付宝选项，调用 `uni.requestPayment({ provider: 'alipay', orderInfo })`
- 回调仍走 `/aliPay/cert_notify_url`（或 `notify_url`）
- 需配置有效的支付宝密钥/证书；微信小程序内支付宝能力受端限制，**App/支付宝小程序**更完整

---

## 4. 数据库脚本使用顺序

```text
1. baseline 或 upgrade
2. quartz/01_biz_jobs.sql
3. menu/01_align_job_menus.sql
4. 后台启动定时任务 + 重新登录
```
