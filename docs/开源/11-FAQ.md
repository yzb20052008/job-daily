# 11 常见问题（FAQ）

---

## 部署与环境

**Q：必须用 Jeecg 全量系统库吗？**  
A：管理端登录、权限、字典依赖 Jeecg 体系。新环境需具备系统表 + 本仓库 `db` 业务脚本。若你已有 Jeecg 库，按 upgrade 增量对齐即可。

**Q：Java 17 能跑吗？**  
A：工程面向 Java 8/11。Java 17+ 需自行验证依赖与反射配置，开源文档不默认支持。

**Q：Redis 可以不做吗？**  
A：不建议。登录、缓存、部分防重依赖 Redis；生产务必部署。

## 业务

**Q：和 BOSS 直聘一类产品区别？**  
A：本项目侧重日结短单：打卡与线上结算；不是长周期简历招聘。

**Q：没有支付商户能演示吗？**  
A：可演示到待结算；真实入账需配置支付。可用微信/支付宝沙箱或小额实测。

**Q：支付宝在微信小程序里能付吗？**  
A：受端能力限制，App/支付宝小程序更完整；以各端实际能力为准。

## 资金

**Q：回调了两次会不会加两笔余额？**  
A：正常实现应幂等；上线前必须用重复通知验证。若旧版本存疑，请对照最新 `paySalarySuccess` 逻辑。

**Q：提现一直「待用户确认」？**  
A：新版商家转账常需用户在小程序确认收款；可查单回写或引导用户打开确认页。见提现异常说明文档。

## 开源与授权

**Q：可以商用吗？**  
A：在 Apache-2.0 条款下可以；请保留 LICENSE/NOTICE，自担合规，建议更换品牌。

**Q：可以拿去卖源码吗？**  
A：许可证未禁止销售副本，但须遵守 Apache-2.0 归属与声明义务，且不得虚假宣称「官方唯一」。维护者可对恶意倒卖不做技术支持。

**Q：哪里能在线体验？**  
A：微信扫码体验小程序（见 [images/mobile-mp-qrcode.jpg](images/mobile-mp-qrcode.jpg)）；管理后台 [http://lg.qinkonglan.cn/](http://lg.qinkonglan.cn/)，账号 `test` / `test@123`。界面截图见 [01-产品介绍](01-产品介绍.md) 第 6 节。

**Q：有技术问题怎么办？**  
A：请在代码托管平台提交 **Issue**，标明端（Admin / Web / Mobile）与复现步骤。见 [贡献指南](09-贡献指南.md)。

**Q：如何获取商业支持？**  
A：见 [10-商业支持](10-商业支持.md)。
