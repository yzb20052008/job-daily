# 10 商业支持

开源版已包含日结招工主链路与三端源码，便于学习、私有部署与二次开发验证。

若你需要**可签约、可验收、可运维**的商业交付，可基于本项目开展以下合作（内容可裁剪）。

---

## 1. 服务内容（示例）

| 类型 | 说明 | 适用 |
|------|------|------|
| 部署实施 | 环境规划、HTTPS、回调、菜单与任务启用、冒烟验收 | 无研发团队 |
| 品牌换皮 | Logo、名称、主题色、小程序装修 | 区域运营商 |
| 支付联调 | 微信/支付宝商户、转账、对账、异常预案 | 准备真实结算 |
| 功能定制 | 工种规则、城市运营、报表、对接 ERP/HR | 有明确 SOP |
| 版本升级 | 安全补丁、商业增强模块、培训 | 长期运营 |
| 运维托管 | 监控告警、备份、应急（另签 SLA） | 生产稳定要求高 |

具体范围、工期、费用以双方商务合同为准。

---

## 2. 开源与商业边界（建议口径）

| 开源仓库 | 商业交付 |
|----------|----------|
| 源码与 Apache-2.0 权利 | 实施服务、定制代码、闭源增强包（若单独授权） |
| 社区 Issue 答疑（尽力） | 工单响应时效、专属群、现场支持 |
| 文档与脚本 | 针对客户环境的部署手册与验收报告 |

**获客、劳务合规、支付商户申请**通常由客户自行负责；可约定咨询协助但不替代持牌义务。

---

## 3. 联系方式

请通过以下**正规渠道**沟通（请维护者按实际填写）：

1. 代码托管平台 Issue，标题前缀 `[商务]`  
2. 官方邮箱：`YOUR_BUSINESS_EMAIL@example.com`（发布前替换）  
3. 官方网站 / 文档站点：（发布前替换）  

请勿在 README 中堆砌个人即时通讯账号，以免触发托管平台「广告导流」风控。

---

## 4. 售前请准备的信息

为加快评估，请提供：

- 使用城市 / 行业、预估日活发岗量  
- 是否需要真实结算与提现  
- 是否已有微信小程序与支付商户  
- 期望上线时间与是否要多品牌  
- 是否接受私有化服务器（云厂商与地域）  

---

## 5. 声明

商业服务与开源许可证相互独立。未签约前，维护者无义务提供免费部署或无限改需求。开源软件按「现状」提供，商业合同另约定验收标准与质保。
