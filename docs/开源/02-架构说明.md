## 2. 后端模块划分（`Job-Daily-Admin`）

| 模块 / 包 | 职责 |
|-----------|------|
| `qkl-module-system` | 系统用户、权限、字典、启动入口 |
| `qkl-module-job` | **日结招工核心业务** |
| `qkl-base-core` | 公共能力 |

`qkl-module-job` 内主要业务包：

| 包名 | 职责 |
|------|------|
| `api` | 移动端 REST（`/api/*`） |
| `job` | 岗位、订单、打卡、评价、企业 |
| `pay` | 微信 / 支付宝 / 转账 |
| `ums` | 账户、提现、实名、VIP |
| `integral` | 积分、道具、充值 |
| `cms` | 公告、广告、通知 |
| `ops` | 运营工作台 |
| `msg` | 业务消息模板 |
| `finance` | 对账等 |
| `quartz` | 订单/岗位/对账/告警任务 |
| `rule` | VIP 权益等规则入口 |

## 3. 前端工程

### 3.1 管理端 `Job-Daily-Web`

- 技术：Vue2 + Ant Design Vue + Jeecg 前端脚手架  
- 业务页：`src/views/job|ums|integral|cms|ops` 等  
- 环境变量：`.env.development` / `.env.production`（API 地址）

### 3.2 移动端 `Job-Daily-Mobile`

- 技术：UniApp + uView  
- 配置：`config/baseUrl.js`、`config/api.js`、`config/request.js`  
- 页面：岗位、订单、打卡、钱包、简历、我的等

## 5. 关键外部依赖

| 依赖 | 用途 | 备注 |
|------|------|------|
| 微信小程序 | 登录、订阅消息、JSAPI 支付 | 需自有 AppId |
| 微信商家转账 | 提现到零钱 | 需商户号与证书 |
| 支付宝 | 可选结算渠道 | 证书/密钥自备 |
| Redis | 缓存、会话、防重等 | 生产高可用建议 |
| OSS / 本地文件 | 图片凭证 | 按 Jeecg 文件配置 |
| 地图服务 | 定位/距离 | **替换为自有 Key** |

---

## 6. 安全与分层原则

1. **服务端为准**：订单状态、金额、提现必须后端校验  
2. **幂等**：支付/转账回调可重复到达  
3. **配置外置**：密钥不进 Git  
4. **最小权限**：管理端接口走权限码；移动端校验订单当事人
