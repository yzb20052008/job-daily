# 05 部署指南

面向生产或预发环境的部署说明。本地调试请先阅读 [04-快速开始](04-快速开始.md)。

---

## 1. 部署拓扑建议

```text
                   ┌─────────────┐
 用户 ───────────► │ Nginx/WAF   │
                   └──────┬──────┘
          ┌───────────────┼───────────────┐
          ▼               ▼               ▼
   静态管理端         API 后端         可选静态 H5
   (Web dist)     (Spring Boot)      (UniApp H5)
          │               │
          │               ├── MySQL（主从可选）
          │               └── Redis
          │
   微信回调 / 支付回调 ──► 公网 HTTPS 域名指向 API
```

要求：

- API **必须 HTTPS**（支付与小程序合法域名）  
- 管理端建议仅内网或强鉴权访问  

---

## 2. 后端部署

### 2.1 构建

```bash
cd Job-Daily-Admin
mvn -pl qkl-module-system/qkl-system-start -am clean package -DskipTests
```

产物一般位于：

`qkl-module-system/qkl-system-start/target/*.jar`

### 2.2 运行示例

```bash
java -jar qkl-system-start.jar --spring.profiles.active=prod
```

或使用 systemd / Docker（自行编写，仓库未强制提供）。

### 2.3 生产配置

- 使用 `application-prod.yml`（或配置中心）  
- 数据源、Redis、文件存储、微信、支付证书路径使用**服务器本地或密钥管理系统**  
- 关闭或加固 Druid 监控、Actuator  

清单见 [06-配置说明](06-配置说明.md)、[08-安全合规](08-安全合规.md)。

---

## 3. 数据库发布

1. 备份生产库  
2. 按 `Job-Daily-Admin/db/README.md` 顺序执行尚未执行的 `upgrade`  
3. 记录已执行版本号（建议自建 `schema_version` 表或运维台账）  
4. **禁止**对生产执行 `demo/01_clean_biz_data.sql`  

---

## 4. 管理端部署

```bash
cd Job-Daily-Web
npm ci
# 配置 .env.production 中 VUE_APP_API_BASE_URL
npm run build
```

将 `dist/` 交由 Nginx 托管，并配置 API 反向代理（避免浏览器跨域）。

---

## 5. 移动端发布

1. 修改生产 `baseUrl`、`shareUrl`  
2. 替换地图 Key、小程序 AppId  
3. HBuilderX 发行 → 微信小程序  
4. 微信公众平台配置：request 合法域名、uploadFile、支付目录等  
5. 提交审核（类目选择需符合日结/用工相关规范，由运营方负责）  

---

## 6. 支付与回调

| 渠道 | 典型回调路径（以代码为准） | 注意 |
|------|----------------------------|------|
| 微信 V2 支付通知 | `/wxPay/payNotify` | 验签、幂等、金额校验 |
| 微信 V3 / 转账 | `/v3/payNotify`、`/v3/transferNotify` | 平台证书、商户证书 |
| 支付宝 | `/aliPay/*notify*` | 验签、商户单号路由 |

上线前：

- [ ] 商户平台回调 URL 与域名一致  
- [ ] 证书文件权限受限（不可 Web 直接下载）  
- [ ] 沙箱或小额真实支付走通入账与提现  

---

## 7. 定时任务

在管理端「定时任务」中启用业务 Job（脚本已写入时）：

- 订单超时：`OrderJob`  
- 岗位下架：`PostJob`  
- 资金对账：`FinanceReconJob`  
- 其他积分/告警相关任务按环境启用  

告警 Webhook 配置见 upgrade 脚本与 [改造计划](../改造升级计划.md)。

---

## 8. 上线检查清单（Go/No-Go）

| 类别 | 检查项 | 结果 |
|------|--------|------|
| 配置 | 无默认口令、无仓库密钥 | ☐ |
| 网络 | HTTPS、回调可达 | ☐ |
| 业务 | 完整一单冒烟通过 | ☐ |
| 资金 | 重复回调不入双份账 | ☐ |
| 提现 | 失败解冻、成功扣冻结 | ☐ |
| 备份 | DB 备份与回滚方案 | ☐ |
| 监控 | 应用日志、磁盘、证书有效期 | ☐ |
| 合规 | 小程序类目、隐私协议、用户协议 | ☐ |

任一项未完成，不建议对真实用户开放结算与提现。

---

## 9. 回滚

1. 应用回滚上一版本 jar / 前端 dist  
2. DB 仅执行附带回滚说明的脚本；无回滚脚本时靠备份还原  
3. 支付中状态订单人工对账后再开放入口
