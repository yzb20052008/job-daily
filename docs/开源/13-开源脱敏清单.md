# 13 开源脱敏清单

开源发布或对外推送前，按本清单核对。

**配置约定（就近放置，勿集中堆到 private/）：**

| 提交 Git | 仅本地（gitignore） |
|----------|---------------------|
| `application-*.yml.example` | `application-*.yml` |
| `production/*.properties.example` | `production/*.properties` |
| `baseUrl.js.example` | `baseUrl.js` |
| `.env.*.example` | `.env.development` / `.env.production` |

`private/` 仅作可选个人备份（如 SQL dump），不是主配置路径。

---

## 1. 必须脱敏 / 移出公开树

| 类型 | 工程内位置 | 处理 |
|------|------------|------|
| 后端环境配置 | `qkl-system-start/.../application-*.yml` | 忽略跟踪；提交 `*.yml.example` |
| 支付配置 | `resources/production/*.properties` | 忽略跟踪；提交 `*.example` |
| 证书 | `*.pem` / `*.p12` | 不进库；部署机安全路径存放 |
| 管理端 API | `Job-Daily-Web/.env.production` | 忽略跟踪；提交 `.env.production.example` |
| 移动端域名 | `Job-Daily-Mobile/config/baseUrl.js` | 忽略跟踪；提交 `baseUrl.js.example` |
| 移动端 OSS 直传 | ~~`ossutil-config.js`~~ | **已废弃**：OSS 仅配服务端 `jeecg.oss.*` |
| 全量 SQL dump | `db/qkl-job.sql`、`job-daily.sql` | gitignore；可选备份到本地 `private/sql-dumps/` |
| 源码硬编码密钥 | 工具类 `main` | 禁止写回真实值 |
| 运营 CDN | 业务域名 | 示例用 `cdn.example.com` / `api.example.com` |

---

## 2. 建议保留在开源（可公开）

- `docs/开源/**` 正式文档  
- `db/baseline|upgrade|menu|quartz|demo` 结构与种子（demo 仅测试）  
- 业务源码（已去掉密钥）  
- `LICENSE` / `NOTICE` / `SECURITY.md`  
- 各模块旁的 `*.example` 模板  

---

## 3. 发布前命令（示例）

在仓库根目录：

```bash
# 敏感关键词（排除 private 与编译产物）
rg -n "qinkonglan\\.cn|LTAI5t|password: 1988|875a7ab8|易祖柏|oAG2m7U" -g "!private/**" -g "!**/unpackage/**" -g "!**/target/**" -g "!**/node_modules/**"

# 确认忽略生效
git check-ignore -v Job-Daily-Admin/qkl-module-system/qkl-system-start/src/main/resources/application-dev.yml
git check-ignore -v Job-Daily-Mobile/config/baseUrl.js
git check-ignore -v Job-Daily-Web/.env.production
```

出现命中：先改为占位或移出跟踪，再推送。

---

## 4. 密钥轮换（重要）

若真实密钥曾进入过 Git 历史或公开过：

1. **立即轮换**：OSS、短信、微信 AppSecret、支付密钥、邮箱授权码、数据库口令  
2. 公开仓库建议新仓库或 `git filter-repo` 清洗历史（高级操作，单独评估）  
3. 微信/支付商户平台作废旧证书并重新下载  

仅改工作区文件**不能**消除已推送历史中的泄露。
