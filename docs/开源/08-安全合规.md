## 2. 上线前安全清单

### 2.1 密钥与配置

- [ ] 删除/替换所有演示口令、JWT 密钥、微信 secret、支付密钥  
- [ ] 证书仅存放于服务器安全目录，备份加密  
- [ ] 地图、OSS、短信 Key 使用自有账号  
- [ ] `.gitignore` 生效，历史提交中若曾泄露密钥需轮换  

### 2.2 应用与接口

- [ ] 管理端强密码 + 验证码/二次验证  
- [ ] 关闭公网调试端点、多余 Swagger（或加访问控制）  
- [ ] 支付回调验签失败拒绝入账  
- [ ] 订单/提现接口校验登录身份与数据归属  
- [ ] 上传文件类型与大小限制，防木马上传  

### 2.3 基础设施

- [ ] HTTPS 与证书自动续期  
- [ ] 数据库仅内网；定期备份与恢复演练  
- [ ] Redis 设置密码且不暴露公网  
- [ ] WAF / 限流（登录、支付、提现）  

### 2.4 数据与隐私

- [ ] 隐私政策、用户协议上线  
- [ ] 实名信息脱敏展示与最小权限访问  
- [ ] 日志禁止打印完整证件号、支付密钥、银行卡  

---

## 3. 资金安全专项

1. 金额以后端核算与渠道回执为准  
2. 回调幂等键：商户订单号 / 提现 out_bill_no  
3. 提现冻结与解冻成对出现，禁止无单号强行成功  
4. 日终对账任务开启，异常进运营台  
5. 生产先小额灰度  

相关实现说明见业务补强文档与 `pay`、`ums` 包。

---

## 4. 小程序与内容合规

- 类目、用户生成内容审核、投诉入口由运营配置  
- 订阅消息模板需在微信平台申请  
- 禁止诱导分享、虚假日结承诺等违规运营行为
