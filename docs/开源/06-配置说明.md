# 06 配置说明

本文说明配置分类与原则。**具体键名以仓库内 yml / 前端 env 为准**，部署时对照修改。

---

## 1. 原则

1. 密钥、证书、生产域名**不得**提交到 Git  
2. 模板与真实文件**放在同一目录**：`xxx.example`（入库）→ 复制为 `xxx`（本地）  
3. 生产与开发配置分离（`dev` / `prod`）  
4. 开源克隆后第一步：按各目录 `*.example` 复制并填写；**不要**依赖集中式 `private/` 作为唯一配置源  

---

## 2. 后端（Spring）

路径：

`Job-Daily-Admin/qkl-module-system/qkl-system-start/src/main/resources/`

```text
application-dev.yml.example   →  application-dev.yml
application-prod.yml.example  →  application-prod.yml
production/*.properties.example → production/*.properties
```

| 类别 | 典型配置 | 说明 |
|------|----------|------|
| 数据源 | `spring.datasource` | URL、账号、口令 |
| Redis | `spring.redis` | 主机、密码、库号 |
| 上传 | 后台 `/api/file/upload`（`jeecg.uploadType` + `jeecg.oss.*`） | **禁止**客户端持有 OSS Secret |
| 微信小程序 | appId、secret | 登录与消息 |
| 微信支付 | mchId、证书路径、APIv3 密钥、通知域名 | 工资与转账 |
| 支付宝 | appId、密钥/证书、回调域名 | 可选 |
| 任务告警 | webhook URL | 定时任务失败通知 |

---

## 3. 管理端（Vue）

路径：`Job-Daily-Web/`

```text
.env.development.example  →  .env.development
.env.production.example   →  .env.production
```

关键变量示例：`VUE_APP_API_BASE_URL`

---

## 4. 移动端（UniApp）

路径：`Job-Daily-Mobile/config/`

```text
baseUrl.js.example  →  baseUrl.js
```

| 文件 | 用途 |
|------|------|
| `baseUrl.js` | API 根地址、分享域名（本地文件） |
| `config/api.js` | 接口路径聚合 |
| `config/request.js` | 拦截器、Token |
| `manifest.json` | 小程序 AppId、权限 |

正式地图 Key 配在后台 `base_config.map_key`；逆地理走 `/api/map/*`。

---

## 5. 数据库业务开关

部分规则通过 `base_config` 或同类配置表控制，例如：

- 打卡半径  
- 评价超时  
- 待开工过期自动取消  

以干净库 `db/00_job_daily_clean.sql` 中的 `base_config` 种子及管理端「基础配置」维护为准（`map_key` 等需自行填写；腾讯控制台请勿对该 Key 开启签名校验）。

---

## 6. 微信商户平台需人工配置的项

- JSAPI 支付授权目录 / 小程序绑定  
- 支付结果通知 URL  
- 商家转账通知 URL（如 `/v3/transferNotify`）  
- 证书与密钥轮换计划  

代码中的 notify 路径以实际 Controller 映射为准，部署后用日志验证首次回调。

---

## 7. 配置检查命令（建议）

发布前在仓库根目录本地执行（勿在日志中打印密钥）：

- 搜索疑似密钥：`password`、`secret`、`apiKey`、`BEGIN PRIVATE KEY`  
- 确认 `.gitignore` 已忽略本地 yml、证书、`.env.local`  

安全要求见 [08-安全合规](08-安全合规.md)。
