# 04 快速开始

目标：在开发机跑通「后端 + 管理端」，并可用微信开发者工具打开移动端（需自备小程序账号）。

---

## 1. 环境要求

| 组件 | 建议版本 |
|------|----------|
| JDK | 8 或 11（勿用 17+ 除非已完整验证） |
| Maven | 3.6+ |
| MySQL | 5.7+ / 8.0（注意排序规则 utf8mb4） |
| Redis | 5.0+ |
| Node.js | 14.x～16.x（管理端 Vue2 项目） |
| HBuilderX | 正式版（移动端） |
| 微信开发者工具 | 最新稳定版 |

---

## 2. 获取源码

```bash
git clone <your-repo-url> daily
cd daily
```

---

## 3. 初始化数据库

1. 创建库（示例名 `job-daily`），字符集 `utf8mb4`  
2. 导入 Jeecg 系统基础库（若你使用完整 Jeecg 初始化脚本；以你环境既有体系为准）  
3. 执行业务脚本，顺序见：

[Job-Daily-Admin/db/README.md](../../Job-Daily-Admin/db/README.md)

最小业务相关：

```text
baseline/01_job_core_tables.sql
quartz/01_biz_jobs.sql
menu/*.sql
upgrade/*.sql（按文件名时间顺序）
```

可选 Demo：`db/demo/`（**禁止在生产执行清理脚本**）。

---

## 4. 配置后端

1. 复制示例配置：

```text
Job-Daily-Admin/qkl-module-system/qkl-system-start/src/main/resources/
  application-dev.yml.example  →  application-dev.yml
```

2. 修改：数据源、Redis、上传、微信与支付相关项（见 [06-配置说明](06-配置说明.md)）  
3. 确认 `application.yml` 中 `spring.profiles.active=dev`

---

## 5. 启动后端

```bash
cd Job-Daily-Admin
mvn -pl qkl-module-system/qkl-system-start -am package -DskipTests
# 或使用 IDE 运行
# org.jeecg.JeecgSystemApplication
```

默认端口以配置为准（常见 `8080`/`8081`）。健康检查：访问接口文档或登录页代理目标是否可达。

---

## 6. 启动管理端

```bash
cd Job-Daily-Web
npm install
# 修改 .env.development 中的 VUE_APP_API_BASE_URL 指向后端
npm run serve
```

使用管理员账号登录（以你库中初始化账号为准，**生产必须改密**）。

菜单若缺失：确认已执行 `db/menu` 脚本并**重新登录**。

---

## 7. 启动移动端

1. HBuilderX 打开 `Job-Daily-Mobile`  
2. 编辑 `config/baseUrl.js`：`baseUrl` 指向后端（开发可用局域网 IP）  
3. 替换地图 Key 等为自有配置  
4. 运行 → 微信开发者工具；配置小程序 AppId（manifest）  

接口封装见 `config/api.js`、`config/request.js`。

---

## 8. 最小业务冒烟

1. 管理端审核通过一个岗位（或 Demo 种子）  
2. 工人报名 → 老板确认  
3. 工人上班/下班打卡  
4. 老板结算（需支付沙箱或真实商户）  
5. 评价完成  

无支付条件时，可先验证到「待结算」状态，支付联调见 [05-部署指南](05-部署指南.md)。

---

## 9. 常见卡点

| 现象 | 处理 |
|------|------|
| 跨域 | 管理端走 devServer 代理；核对 API 前缀 |
| 401 | Token 头、Shiro 放行列表、时间差 |
| 菜单空白 | 执行菜单 SQL + 清缓存 + 重新登录 |
| 小程序 request 合法域名 | 开发工具勾选不校验；正式版配置服务器域名 |
