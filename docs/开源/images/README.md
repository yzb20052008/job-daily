# 截图与演示资源

本目录存放开源仓库展示用截图（语义化英文文件名，便于引用与跨平台）。

## 文件清单

| 文件 | 说明 |
|------|------|
| `mobile-home.jpg` | 移动端首页（附近岗位、距离） |
| `mobile-message.jpg` | 消息中心（系统/订单/动账） |
| `mobile-order-worker.jpg` | 工人端「我的订单」 |
| `mobile-mine-worker.jpg` | 工人端「我的」（角色切换入口） |
| `mobile-post-detail.jpg` | 职位详情与报名 |
| `mobile-order-boss.jpg` | 老板端「我的订单」（员工管理） |
| `admin-post-list.png` | 管理端招工信息列表 |
| `admin-order-list.png` | 管理端订单信息列表 |
| `admin-user-list.png` | 管理端用户列表 |
| `admin-base-config.png` | 管理端基础配置 |

## 引用示例

在 `docs/开源/` 下 Markdown：

```markdown
![移动端首页](images/mobile-home.jpg)
```

在仓库根 `README.md`：

```markdown
![移动端首页](docs/开源/images/mobile-home.jpg)
```

请避免大量外部图床链接，以免托管平台误判为广告导流。
